# Non-bank brands often used in Malaysian phishing links: couriers, e-wallets,
# marketplaces, telcos and government agencies (SRS US-04, ADR-007).
# Added after the held-out samples showed fake Pos Laju, J&T, Touch 'n Go,
# Shopee and gov.my links going unnoticed.
#
# !! VERIFY BEFORE RELEASE !!
# Check each official domain by hand against the brand's own website. Nothing here
# is scraped. A missing official domain makes genuine links show a false warning.
# Last verified: NOT YET VERIFIED
#
# Format: Display name | brand tokens | official domains
# - Brand tokens: a link is suspicious if a part of its host name (split on "." and "-")
#   starts or ends with a token, but the host isn't on an official domain.
# - Official domains: the host may be the domain itself or any subdomain of it.
# - Avoid short tokens that are everyday words or prefixes ("digi" matches "digital",
#   "mudah" is the BM word for "easy", "polis" matches "polish").
# - Put specific agencies before "Malaysian government": the first match names the brand.
